# Churn Prediction App

A web application for predicting customer churn using a TypeScript frontend and Python-based machine learning or data-processing components.

## Overview

Customer churn prediction helps businesses identify customers who may stop using their product or service. This application provides a foundation for analyzing customer information and generating churn predictions through a web interface.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm
- [Python](https://www.python.org/) 3.8 or newer
- pip

### Installation

Clone the repository:

```bash
git clone https://github.com/yhrouk/churn-prediction-app.git
cd churn-prediction-app
```

Install the project dependencies according to the package and requirements files included in the repository.

For the TypeScript/JavaScript application, run:

```bash
npm install
```

For the Python components, run:

```bash
pip install -r requirements.txt
```

> If a `requirements.txt` file is not included, install the Python dependencies documented by the project before starting the application.

## Running the Application

Use the scripts defined in `package.json` to start the application:

```bash
npm run dev
```

If the project uses a separate Python service, start it with the command documented in the relevant Python entry point or configuration file.

## Usage

1. Start the application.
2. Open the local URL shown in the terminal.
3. Enter the required customer information.
4. Submit the information to receive a churn prediction.
